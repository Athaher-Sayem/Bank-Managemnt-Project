# Bank Management System — design-only showcase

Open `index.html` directly or serve this folder with `python -m http.server 8000`. The responsive page is a **static interpretation**, not a replacement for the Windows console program. The two accessible tabs change explanatory text only; they do not read files, authenticate anyone, simulate transactions, or store data.

Source inspected at starting `main` commit `3da9661e583611e9b78eac7ccdefa3a5751eb724`: `README.md` and `Bank managemnt system with file.cpp`. The README calls this second-semester C coursework, while the principal source has a `.cpp` extension and uses Windows console APIs. The repository also contains `Record.txt`; **no content from that file or hard-coded credentials** appears in this showcase. Password encryption, GUI, improved validation and transaction history are README future improvements, not represented here as existing features.

Direction: a coursework ledger rather than a fintech landing page. Deep teal `#173b43`, paper `#efeee7`, copper `#bb7457`, Fraunces headlines and DM Sans text. The ledger and terminal are CSS illustrations, not screenshots of account data. Desktop, tablet and mobile full-page captures live under `assets/screenshots/`.
